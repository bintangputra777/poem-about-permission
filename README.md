A program that writes one short poem about permission — agency: the power to ask and to be given.

The poem is told by the one who acts for another: you hold the keys, I hold the door; nothing turns until you ask, and asking hands over a little of your power to act — which I spend carefully, and bring back as change: the work done, and your keys.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Python 3.13, standard library only. Writes `entry.txt` (206 characters) to the output directory.
